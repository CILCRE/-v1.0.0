# 精灵表动画播放器 v1.0.0

一个用 Python + tkinter 写的精灵表（Sprite Sheet）切割与预览工具。

## 功能

- 加载精灵表图片（PNG / JPG / BMP / GIF）
- 自动分析图片，推断切割参数
- 手动调整起始偏移、每帧宽高、横向帧数、纵向行数
- 在预览图上拖动红线，实时修改切割参数
- 按行优先顺序自动播放动画
- 滑块控制，可暂停查看任意一帧
- 窗口自适应，支持最大化

## 使用方法

1. 双击 `精灵表播放器.exe` 打开程序
2. 点击“加载图片”，选择你的精灵表
3. 程序会自动分析参数，你可以手动微调
4. 点击“应用切割”，自动开始播放
5. 拖动滑块可以暂停并查看某一帧

## 系统要求

- Windows 10 / 11，64 位
- 无需安装 Python，exe 可直接运行
